# Тесты

Три набора, все проходят на сборке 3.0.0 (Windows 11, Node 26.7).

## 1. `engine/test.mjs` — 32/32
Базовый контракт движка:
- триаж: PE (импорты, PDB, Rich, подпись, TLS), PNG, PLN-контейнер BIM, ELF/ZIP;
- память: дедупликация, уровни доверия, FTS5, бюджет контекста в байтах;
- безопасность: файл-инъекция в имени, вырезание секретов, sha256 не маскируется;
- граф: честный счётчик применённых связей, запрет `origin=user` от агента;
- консолидация: кластер → наблюдение с подтверждениями, повтор не дублирует;
- MCP: `initialize`, `tools/list`, неизвестный инструмент — явная ошибка;
- recall@5 на русских и английских RE-фактах ≥ 0.9.

```
node test.mjs
итого: 32 тестов, провалов: 0
```

## 2. `engine/deep-test.mjs` — 8/8
Через живой MCP-канал, с реальной моделью e5:
- 28 инструментов, имена без двойного префикса;
- запись факта с вектором; косинус пары 0,94;
- гибридный recall: перефраз «кладка сорок сантиметров» находит «кирпич 400 мм»;
- `lsre_similar` находит по смыслу;
- `stats` видит embeddings; ответ recall 727 Б.

```
set LSRE_EMBED_DIR=<папка модели>
node deep-test.mjs
итого: провалов 0
```

## 3. `engine/tools-test.mjs` — 7/7
Полный набор:
- `lsre_parse_format` на PNG: 256×256, bitDepth 8, ответ 284 Б;
- неизвестный формат — честный отказ со списком поддерживаемых;
- `lsre_parse_yaml`: текст разобран; битый YAML — ошибка с позицией;
- `lsre_yara_scan`: совпадение правила `crypto_aes_sbox` на эталонных байтах;
- `lsre_frida_status`: библиотека доступна.

## Замеры эмбеддингов
8 запросов × 12 фактов, CPU:

| модель | загрузка | скорость | recall@1 | recall@3 | косинус пар |
|---|---|---|---|---|---|
| rubert-tiny2 int8 (312d) | 150 мс | 2 мс/текст | 7/8 | 8/8 | 0,709 |
| **e5-small int8 (384d)** | 374 мс | **5 мс/текст** | **8/8** | 8/8 | **0,917** |

Потеря от int8-хранения вектора: ≤ 0,0005 косинуса.

## Ручные проверки оболочки
- запуск в чистой папке `%TEMP%` без системного Node — окно открывается, конфиг указывает
  на вложенный `engine\node.exe`;
- плагин в реестре: 28 инструментов `lsre_*`, вызов даёт evidence `engine: plugin:lsre`;
- снимки экранов: приветствие, карта архитектуры, выбор файла во вкладке «Код».

## Чего в тестах нет (честно)
- UI-автотестов оболочки (`cargo test` upstream не прогонялся на GNU-тулчейне целиком);
- тестов Ghidra/Frida на живых процессах (требуют внешних программ и прав);
- нагрузочных тестов на файлах > 64 МБ (стоят лимиты).
