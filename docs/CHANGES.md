# Изменения

## 3.1.0 (12.11.2026) — редактор макетов внутри LSRE
- Вкладка «Графика» = полноценный векторный редактор (UI-крейт FigCraft) внутри LSRE, без отдельного окна.
- Урезанная копия FigCraft: убраны совместная работа, сервер, плагины, PDF, web; exe редактора 83,5 МБ.
- Логотип и название FigCraft в интерфейсе убраны, стартовый экран обезличен.
- Единый шрифт IBM Plex Sans Condensed — без «квадратов» в кириллице.
- Акцентный цвет LSRE и редактора — #C07014 (оранжевый, глаза гарпии) вместо синего/бирюзового.
- Тёмная тема редактора синхронизирована с LSRE.
- Версия 3.0.0 (три zip-архива, без редактора) остаётся доступной отдельным релизом.
## 3.0.0 — 11.11.2026

### Движок (новое)
- **Память v2:** таблица `embeddings`, миграция с копией `.v1.bak`, int8-квантование.
- **Гибридный поиск:** BM25 + косинус + свежесть через RRF, поле `why` в ответе.
- **Эмбеддинги двух профилей:** multilingual-e5-small (384d, unigram) и rubert-tiny2
  (312d, wordpiece); выбор по файлам модели, префиксы `query/passage` из `meta.json`.
- **Kaitai-парсеры:** PNG, SQLite3, gzip, pcap (`lsre_parse_format`).
- **YAML → JSON:** `lsre_parse_yaml`, лимит 1 МБ, теги не исполняются.
- **YARA-X:** `lsre_yara_scan`, разбор JSON-вывода 1.22, свои правила.
- **Frida:** `lsre_frida_status`.
- **Исправлено:** Ghidra больше не ищет путь разработчика — `GHIDRA_INSTALL_DIR` или автопоиск;
  Java — `JAVA_HOME` или PATH.
- **Имена для плагинов:** `LSRE_PLAIN_NAMES=1` — без двойного префикса `lsre_lsre_*`.

### Оболочка (форк)
- **Макеты на вкладке «Графика»**: открытие SVG (превью + список элементов), `.fig/.figcraft`
  (метаданные), выбор элемента → задание → `.spec.md`; кнопка «Запомнить в LSRE» пишет
  спецификацию в память с эмбеддингами, «Поиск по смыслу» — гибридный recall движка.
- **Лента режимов в стиле браузера**: четыре закладки «Чат · Код · Архитектура · Графика».
- **Вкладка «Графика»**: запуск FigCraft v0.17.0 (открытый редактор интерфейсов, MIT) из портативной
  папки `figcraft\`; без логотипов и внешних иконок. Встраивание FigCraft как встроенного редактора —
  отдельный проект (другой движок, сотни тысяч строк Rust).
- Брендинг LSRE: окно, приветствие, About, ресурсы exe, каталог данных `lsre`.
- Векторная иконка-гарпия (SVG) + многоразмерный `.ico`; белый фон углов убран.
- `clean_room.rs`: инструменты `lsre_*` разрешены в Clean room.
- Лента **Чат · Код · Архитектура**; новая вкладка «Код» (просмотр файлов проекта).
- Экран «Архитектура»: карта сверху вниз, зум/панорама/перетаскивание, панель деталей,
  сохранение и загрузка JSON.
- Включён PNG-загрузчик `egui_extras` (feature `image`).

### Поставка и тесты
- `start.cmd` + `start.cjs`: конфиг генерируется под папку, вложенный `node.exe` в full.
- `mcp-print.cjs`: готовый MCP-конфиг для Claude Code / Cursor / DSH.
- Тесты: 32/32, 8/8, 7/7; бенчмарк эмбеддингов.
- exe пересобран с `--remap-path-prefix`: локальных путей сборки внутри нет.
