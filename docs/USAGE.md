# Как пользоваться

## Первый запуск
1. `start.cmd` → окно LSRE.
2. Экран приветствия: «Я новичок» (крупные кнопки, простые слова) или «Показать всё»
   (все инструменты, байты, ссылки, доказательства).
3. Переключатель **Глубокий / Чистая комната** в верхней панели:
   - Чистая комната — только внешние признаки (строки, импорты, сигнатура), без чтения кода;
   - Глубокий — полный доступ: декомпиляция, Frida, дампы, наши `lsre_*`.

## Три режима
Лента под заголовком: **Чат · Код · Архитектура**.

- **Чат** — рабочая область проекта: карточки с доказательствами, план шагов
  (Изучить → Собрать → Проверить → Готово), время и стоимость ИИ.
- **Код** — файлы проекта слева, содержимое справа (моноширинно, только чтение),
  кнопки «Копировать путь» и «Папка».
- **Архитектура** — карта узлов: слои сверху вниз, родители выше, дети ниже.
  Колесо — зум, перетаскивание фона — панорама, узла — перемещение, клик — панель деталей.
  «Разложить» — перестроить по слоям, «Сохранить»/«Загрузить» — JSON-карта.

## Работа с файлом
1. Перетащите файл в окно (или укажите путь в чате).
2. Спросите: «что это за файл», «есть ли признаки упаковки», «что делают импорты».
3. На каждый ответ смотрите карточку: чем доказано (смещение, секция, правило).
4. Для тяжёлых ответов используйте пагинацию: инструменты отдают `next_offset` и покрытие.

## Память
- «Запомни: …» — факт сохраняется с эмбеддингом; поиск находит перефразы, а не только слова.
- «Что я знаю про …» — гибридный поиск; в ответе видно `why` (bm25 / косинус / свежесть).
- Банки разделяют темы: `default`, `bim`, `re`, `archicad` и т.д.
- Страницы знаний — долговременные соглашения и архитектура проекта.

## Полезные инструменты
| Задача | Инструмент |
|---|---|
| Быстрый разбор файла | `lsre_triage` (факт-шит ≤ 2 КБ) |
| Разбор + запись в память | `lsre_analyze` |
| PNG / SQLite / gzip / pcap | `lsre_parse_format` |
| YAML-конфиг в JSON | `lsre_parse_yaml` |
| Проверить файл правилами | `lsre_yara_scan` |
| Строки и функции | `lsre_ghidra_open` → `_decompile` / `_strings` / `_xrefs` |
| Живой процесс | `lsre_frida_processes` → `_modules` → `_run` |

## Работа без интерфейса (MCP)
`engine/server.mjs` — MCP-сервер. Подключение к Claude Code / Cursor / DSH описано в
`docs/MCP.md`; готовый JSON печатает `mcp-print.cjs` в папке сборки.

## Приватность
- Никакой телеметрии. Движок не делает сетевых запросов.
- Файлы и память остаются на диске; база — `data\lsre\lite.db`.
- Если включаете облачный ИИ в оболочке — это ваш ключ и ваш выбор; по умолчанию можно
  работать вообще без ИИ (все `lsre_*` детерминированы).
