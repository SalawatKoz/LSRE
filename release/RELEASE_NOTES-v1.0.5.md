# LSRE v1.0.5 — разбор форматов через Kaitai

## Новое

**`lsre_parse_format`** — структурный разбор бинарных файлов по декларативным описаниям
Kaitai Struct (`.ksy`). Парсеры компилируются на этапе сборки в JS и в exe попадают уже
готовыми — компилятор в дистрибутив не входит.

| Формат | Что отдаёт |
|---|---|
| `png` | ширина, высота, глубина цвета, тип цвета, CRC |
| `sqlite3` | размер страницы, кодировка, версии схемы и SQLite |
| `gzip` | метод сжатия, флаги, mtime, OS |
| `pcap` | версия, snaplen, тип сети |

- **Ленивая загрузка:** парсер подключается только в момент вызова; пока инструмент не
  запрошен, код лежит на диске и не потребляет ни память, ни токены.
- **Автоопределение** по сигнатуре; явно — `format`.
- Без `path` возвращает список доступных парсеров.
- Триаж (`lsre_file_triage`) подсказывает, какие парсеры есть: поле `available_parsers`.

## Проверено на собранном exe

| Файл | Результат |
|---|---|
| `region.png` | `format=png`, ширина 560 |
| `lsre.db` | `format=sqlite3`, `pageSize=4096`, `sqliteVersion=3053004` |
| `notepad.exe` (PE) | «формат не распознан» — корректная ошибка, PE-парсер не входит |
| Список форматов | `png/gzip/sqlite3/pcap`, все собраны |

## Ограничения

- Набор форматов маленький (4) и написан вручную под MIT: PE/ELF/ZIP — следующий шаг.
- Разбор идёт из начала файла; смещение начала не поддерживается.
- Ограничение вывода — 256 КБ, глубина — 8, узлов — 20 000.
