# LSRE 2.0.0 — триаж, сигнатуры, форматы, память и визуал

Крупное обновление: LSRE перестал быть «упаковкой REA» и стал отдельным продуктом с
подготовительными слоями, памятью и интерфейсом.

## Новое по сравнению с 1.0.x

| Возможность | Что даёт |
|---|---|
| `lsre_file_triage` | PE: секции с энтропией, импорты, overlay, TLS, .NET, время сборки, упаковщик с уверенностью и уликами |
| `lsre_yara_scan` | YARA-X 1.22 внутри exe + правила MIT: AES, SHA-256, MD5, Base64, UPX, MPRESS, анти-отладка, zlib, OpenSSL |
| `lsre_parse_format` | Kaitai-парсеры PNG, SQLite 3, gzip, pcap — именованные поля вместо смещений |
| Память | SQLite FTS5: факты, граф связей, якоря сессий, страницы знаний |
| Визуал | `LSRE.exe ui` — локальная карта связей с ручной правкой и сохранением позиций |
| Происхождение | `origin: ai/user`; связи, поставленные человеком, агент не перезаписывает |

## Установка

Скачайте `LSRE.exe`, скопируйте в любую папку и запустите. Первый запуск распаковывает
окружение в `%LOCALAPPDATA%\LSRE\6.7.0-lsre2`. Подключение к агенту:

```json
{ "mcpServers": { "lsre": { "command": "C:\\Tools\\LSRE.exe", "args": [] } } }
```

## Ограничения

- Файл не подписан.
- Нативной сборки под Windows on ARM нет.
- Kaitai-парсеры: четыре формата; PE/ELF/ZIP — в работе.
