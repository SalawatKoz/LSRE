# LSRE 2.1.2 — разбор YAML

**Дата:** 26.10.2026
**Файл:** `LSRE.exe` — 334,6 МБ
**SHA-256:** `75EEE6A6E653807EBF4490B6D5469D5CE5F07569702891787A3A72543C88D277`

## Что нового

- **`lsre_parse_yaml`** — разбор YAML в JSON: конфиги, сценарии оркестрации, файлы `.ksy`.
  Возвращает тип, ключи, ошибку с номером строки и столбца.
- Безопасный режим: лимит 1 МБ, `maxAliasCount 100`, теги `!!python/!!js/!!ruby/!!perl` запрещены.
- Режим `keys_only` — только структура, без значений (для больших конфигов).
- **101 инструмент** (83 REA + 18 LSRE). Размер не вырос: парсер `yaml@2.9.0` уже был в payload
  как транзитивная зависимость, поэтому ноль мегабайт.

## Проверено

22 критических теста через MCP: **22/22**.
Добавлены: валидный YAML (сценарий со шагами), битый YAML (ошибка с координатой),
опасный тег (`!!python/object` отклонён).

## Пример

```yaml
scenario: review
steps:
  - tool: lsre_file_triage
  - retry: 2
```
→ `{ "ok": true, "kind": "object", "keys": ["scenario", "steps"] }`
