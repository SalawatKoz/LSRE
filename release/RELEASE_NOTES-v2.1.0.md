# LSRE 2.1.0 — локальная память с русскими эмбеддингами

**Дата:** 26.10.2026
**Файл:** `LSRE.exe` — 334,5 МБ
**SHA-256:** `82C79346078834D71968E1ED9CC367E4AE29D9188E8D79CD5474D60354C267F6`

## Главное

- **Эмбеддинги внутри exe.** Модель rubert-tiny2 (int8, 27,9 МБ, 312 измерений) работает офлайн,
  без API и сети. Инструмент `lsre_embed` возвращает вектор текста или косинус двух текстов.
- **Гибридный поиск по памяти.** Recall использует два канала — FTS5/bm25 и векторное сходство —
  и сливает их через reciprocal rank fusion, поэтому перефразировки находит, а не только точные слова.
- **Схема памяти v4:** таблица `embeddings`; вектор считается в момент сохранения факта.
- **Запасной каталог памяти:** если системная папка недоступна (политика ОС), база уходит
  в `~/.lsre/memory` — вместо падения.
- **Защита от DoS в токенизаторе:** длинные «слова» и тексты > 4000 символов не подвешивают модель.

## Установка

```json
{
  "mcpServers": {
    "lsre": { "command": "C:\\\\Tools\\\\LSRE.exe", "args": [] }
  }
}
```

Первый запуск распаковывает окружение в `%LOCALAPPDATA%\\LSRE` и больше не требует Node, npm или Python.

## Ограничения

- Только Windows x64.
- GPU не используется: 312-мерная модель на CPU занимает ~2 мс, выигрыша от видеокарты нет.
- Авто-attach Frida не выполняется: динамическое подключение к чужому процессу — только по явной команде.
