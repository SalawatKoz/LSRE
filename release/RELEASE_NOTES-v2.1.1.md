# LSRE 2.1.1 — прогрев Frida и консолидация памяти

**Дата:** 26.10.2026
**Файл:** `LSRE.exe` — 334,4 МБ
**SHA-256:** `1488E418483DFC3A88535F2E2234629745D689E4ABC8B004077CAA521E2E6D2A`

## Что нового относительно 2.1.0

- **Frida прогревается при старте.** Устройство инициализируется сразу, поэтому первый
  `instrument_with_frida` не тратит время на инициализацию. Новый инструмент `lsre_frida_status`
  показывает состояние: `ready`, имя устройства, ошибку, если есть. Авто-attach к чужим процессам
  по-прежнему не выполняется — только по явной команде.
- **Консолидация памяти (Hindsight-lite).** `lsre_memory_consolidate` группирует близкие факты
  по эмбеддингам (косинус ≥ 0.8) и создаёт наблюдение с числом подтверждений и списком исходных id.
  Исходные факты не удаляются, режим `dry_run` показывает кластеры без записи.
- **100 инструментов** (83 REA + 17 LSRE).

## Проверено

19 критических тестов через MCP: **19/19**. Добавлены проверки `lsre_frida_status`
(готовность устройства) и `lsre_memory_consolidate` (кластер найден, наблюдение создано).

## Совместимость

Обновление с 2.1.0: exe распаковывает новое окружение (версия `6.7.0-lsre2.1.1`),
старые данные памяти в `LSRE_MEMORY_DIR` сохраняются, схема мигрирует до v4 без потерь.
