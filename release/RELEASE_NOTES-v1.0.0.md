# LSRE v1.0.0 — первый публичный релиз

Первый релиз «Лёгкого старта реверс-инжиниринга»: один exe, MCP-сервер, память между сессиями.

## Файлы

| Файл | Размер | SHA-256 |
|---|---|---|
| `LSRE.exe` | 236 674 048 байт (225,7 МБ) | `61087E23E810B374A55F67BFEFCBB397C135FF24FFF303D3534870DD68789E47` |

## Что внутри

- Node 26.7.0 (вшит), REA 6.7.0 (MIT), Frida 17.
- Ghidra 12.1.4 и JDK 21 подключаются отдельно (пути через `GHIDRA_INSTALL_DIR`, `JAVA_HOME`).
- 94 MCP-инструмента: 83 анализа + 11 памяти.

## Проверено

- `--version` → 6.7.0; `doctor` → Ghidra 12.1.4 найдена.
- `open_binary` + `binary_overview` по `notepad.exe` → PE / x86_64, провайдер Ghidra.
- `list_frida_devices` → 3 устройства.
- Память: запись с вырезанием секретов, поиск по-русски, дедупликация, граф, якорь сессии
  (247 байт), страницы знаний.
- Якорь переживает перезапуск процесса (проверено двумя последовательными запусками exe).

## Изменения относительно REA 6.7.0

- Запуск без `npx` и без обращений к npm.
- Каталог инструментов: 94 вместо 207, схемы ~75 КБ вместо 3084 КБ.
- Бандл минифицирован: `dist` 17,3 МБ вместо 24,7 МБ.
- Удалён Hopper-провайдер (на Windows не работал).
- Добавлена локальная память на SQLite FTS5 с вырезанием секретов.
- Схемы входа `compact`, выходные схемы выключены, лог `warn`.

## Известные ограничения

- Exe не подписан — SmartScreen предупредит о неизвестном издателе.
- IDA/JEB/Cutter/Kuna не входят.
- Нет защиты от параллельного запуска двух агентов.
- Поиск в памяти лексический (без эмбеддингов).

## Установка

Скачайте `LSRE.exe`, сверьте SHA-256, подключите как MCP-сервер:

```json
{ "mcpServers": { "lsre": { "command": "D:\\путь\\LSRE.exe", "args": [] } } }
```
