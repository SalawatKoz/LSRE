# LSRE v1.0.2 — визуал связей

Добавлен локальный визуализатор графа: карта зависимостей, которую агент наполняет, а человек
может разложить и поправить.

## Новое

```powershell
LSRE.exe ui                 # http://127.0.0.1:7788
LSRE.exe ui --port 8080 --bank revit --open
```

- Страница читает ту же SQLite-базу, что и MCP-сервер, и обновляется вживую (SSE).
- Узлы: `binary`, `module`, `function`, `service`; связи: `calls`, `contains`, `imports`,
  `duplicates`, `depends_on`, `similar_to`.
- Раскладки: иерархия зависимостей, кластеры, кольцо, сетка.
- Перетаскивание узлов с сохранением позиций; удаление связи кликом; создание связи
  (Shift-выбор двух узлов → «Связать»); поиск и фильтры по типам связей.
- Граф-движок встроен в exe: интернет не нужен, порт слушается только на 127.0.0.1.

## Исправлено

- Прокси ищет движок рядом с собой; стаб передаёт `REA_ENTRY` — работает на любой машине.
- Lock-каталог при распаковке: два агента не портят окружение.
- Метаданные PE: `ProductName=LSRE`, `FileVersion=1.0.2.0`.
- `PUBLISH.ps1` без локальных путей.

## Проверено

- `LSRE.exe ui --port 7791` → `nodes=3, edges=2`, страница и `cytoscape.min.js` отдаются.
- Банк определяется автоматически, если запрошенный пуст.
- Сброс позиций очищает таблицу `node_positions`.

## Ограничения

- Комфортно до ~300 узлов; большие графы требуют уровней/кластеризации.
- Граф наполняется тем, что записал агент: автоматического обхода бинарников пока нет.
- Exe не подписан.
