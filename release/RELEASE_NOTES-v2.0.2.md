# LSRE v2.0.2 — исправление триажа

## Что изменилось

`lsre_file_triage` неверно читал таблицу каталогов данных PE: смещения были сдвинуты на две
записи, из-за чего признак `.NET` определялся ошибочно.

- теперь `CLR` берётся из 14-й записи, `TLS` — из 9-й;
- проверено на `Archicad.exe` (107 МБ): `.NET=false`, `TLS=true`, 12 секций, 287 импортов;
- на `notepad.exe`: `.NET=false`, `TLS=false`, 8 секций — без изменений.
