# LSRE v1.0.3 — триаж файла и происхождение связей

## Новое

**`lsre_file_triage`** — разбор PE без внешних зависимостей:

- секции: имя, `file_offset`, `rva`, raw/virtual размер, W/X-флаги, **энтропия по каждой**;
- импорты: количество и список DLL;
- overlay, TLS-директория, признак .NET, время сборки;
- подозрение на упаковщик: **уверенность + улики**, без готовых советов модели;
- готовый блок `graph` (бинарник → `depends_on` → DLL) для `lsre_graph_add`.

**Происхождение связей (`origin`)**: `ai` / `user`. Связи, поставленные человеком,
агент перезаписать не может — в SQL он получает `WHERE edges.origin <> 'user'`.
В веб-интерфейсе ручные связи рисуются толще и синим.

## Известные ограничения

- `origin` пока не возвращается в ответе `lsre_graph_query` (хранится и работает, но не в выводе).
- YARA и эмуляция (Unicorn) — не входят, это следующие этапы.
- Триаж только PE; ELF — позже.
