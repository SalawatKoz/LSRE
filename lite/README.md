# LSRE-lite

Лёгкая замена тяжёлой сборки: быстрый триаж + локальная память для экономии токенов.
**Node без npm-зависимостей, SQLite FTS5, без ONNX и без сети.** REA — необязательный мост, не нужен.

## Файлы

| Файл | Что делает |
|---|---|
| `triage.mjs` | Потоковый триаж по смещениям (файл целиком не читается) |
| `memory.mjs` | Память: факты → наблюдения → граф → страницы (4 слоя Hindsight-lite) |
| `server.mjs` | MCP-сервер (stdio JSON-RPC 2.0), 15 инструментов |
| `test.mjs` | 27 регрессионных тестов — по каждому пункту критики v2.2.0 |
| `demo.mjs` | Демо полного конвейера |

## Запуск

```powershell
node test.mjs          # регрессия (должно быть 27/27)
node demo.mjs          # замер на LSRE.exe и notepad.exe
node server.mjs        # MCP-сервер; БД: %LOCALAPPDATA%\lsre-lite\memory.db
node server.mjs --db D:\path\memory.db
```

## Триаж

Читаются только нужные смещения: **286 МБ exe — ~600 мс** (полный конвейер через MCP), notepad — ~14 мс.
PE: машина/битность, секции с энтропией по фактическим байтам, **импорты с именами функций** (не только DLL),
**экспорты с именами**, PDB-путь (CodeView RSDS), Rich header, подпись Authenticode, TLS-callbacks,
overlay, точка входа против секций, эвристики упаковщика. Другие форматы по сигнатуре: ELF, Mach-O,
ZIP/APK/JAR/OOXML, DEX, PDF (с флагами /JavaScript, /OpenAction), PNG/JPEG/GIF, gzip/bzip2/xz/7z/rar,
SQLite, pcap/pcapng, wasm, OLE2, тексты (UTF-8/16, кириллица).

## Принципы (выводы из критики оригинального LSRE)

1. **Никаких голых `catch {}`** — ошибки попадают в `errors` ответа и в stderr. «Молчаливой лжи» нет:
   тип определяется только по сигнатуре, битый MZ → `unknown-mz` + ошибка, а не «pe».
2. **Недоверенные данные помечаются**: всё из файла (имя, DLL, имена функций, PDB) — в
   `<untrusted source="file">…</untrusted>` с вырезанием управляющих символов и экранированием `< >`.
3. **`origin` от агента не принимается** — поля `origin` нет в схеме инструмента; связь, поставленная
   человеком через UI, агент изменить не может. Счётчик `edges_applied` честный: сравнение состояния
   до/после (SQLite `changes()` считает конфликтный UPDATE изменением даже при равных значениях).
4. **Бюджет контекста — байты** (`Buffer.byteLength`), кириллица считается правильно.
5. **Секреты вырезаются одной функцией** (`redact`): Bearer, api_key=, Slack xox, AIza, AKIA, gh*_,
   URL user:pass@, приватные ключи. SHA-хеши не маскируются (это данные, не секреты).
6. **Без эмбеддингов**: FTS5 bm25 + покрытие терминов + RRF(60). recall@5 = 1.0 на 10 русских и
   английских RE-фактах (в тестах). Короткие термины работают: PE, UPX, PDB, TLS, MD5.
7. Консолидация Hindsight-lite — детерминированная: Жаккар по токенам ≥ порога → наблюдение
   с числом подтверждений; покрытые факты не обрабатываются повторно.

## Инструменты MCP

`lsre_analyze` (факт-шит ≤2 КБ + память + граф), `lsre_triage`, `lsre_recall`, `lsre_context`
(бюджет 500–8000 **байт**), `lsre_remember`, `lsre_observe`, `lsre_page_get/set`,
`lsre_anchor`, `lsre_resume`, `lsre_graph_add/query/stats`, `lsre_stats`, `lsre_doctor`.
