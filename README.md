# LSRE — локальный инструмент разбора программ и файлов

**LSRE** — приложение для глубокого разбора бинарей, документов и проектов: триаж, доказательства,
локальная память с эмбеддингами, граф связей, Ghidra, Frida, YARA-X, Kaitai и карта архитектуры —
всё на своём компьютере, без облака и без отправки файлов наружу.

Оболочка — форк открытого интерфейса [Craft Anything](https://github.com/storytold/craft-anything)
(MIT OR Apache-2.0; мы выбрали ветку MIT), переработанная и дополненная. Движок — собственный,
`engine/` в этом репозитории. Обе части открыты.

## Установка

### Вариант 1: портативная сборка (рекомендуется)
1. Скачайте `LSRE-full.zip` из Releases и распакуйте в любую папку (не запускайте изнутри архива).
2. Запустите `start.cmd`. Скрипт создаст `data\config.toml` с путями именно этой папки и откроет окно.
3. Первый экран — приветствие; выберите режим («Я новичок» или «Показать всё»).

Системный Node.js в full-сборке не нужен: внутри `engine\node.exe`. Для lite-сборки нужен
Node.js 22 или новее — https://nodejs.org/

### Вариант 2: подключение как MCP-плагин к агентским терминалам
Движок `engine/server.mjs` — обычный stdio MCP-сервер. В папке собранного пакета выполните:

```
node mcp-print.cjs
```

Скрипт напечатает готовый JSON с абсолютными путями. Дальше:

- **Claude Code:** `claude mcp add-json lsre '<JSON>' --scope user`
- **Cursor:** Settings → MCP → Add server (stdio), те же `command`, `args`, `env`
- **DeepSeek Harness:** блок MCP-сервера в профиле, те же значения

Инструменты появятся как `lsre_analyze … lsre_yara_scan`.

### Вариант 3: собрать самому
Движок (Node 22+):
```
cd engine
node server.mjs          # MCP-сервер на stdio
node test.mjs            # 32 теста
node tools-test.mjs      # 7 проверок полного набора
```
Оболочка (Rust 1.97+ и C++ тулчейн):
```
cd shell
cargo build --release -p craft-anything
```
Подробнее — `docs/INSTALL.md`.

## Возможности

### Инструменты движка (28)
| Группа | Инструменты |
|---|---|
| Триаж и форматы | `lsre_triage`, `lsre_analyze`, `lsre_parse_format` (Kaitai), `lsre_parse_yaml`, `lsre_yara_scan` |
| Память | `lsre_remember`, `lsre_recall`, `lsre_similar`, `lsre_context`, `lsre_observe`, `lsre_page_get/set`, `lsre_anchor`, `lsre_resume`, `lsre_stats`, `lsre_doctor` |
| Граф | `lsre_graph_add`, `lsre_graph_query`, `lsre_graph_stats` |
| Реверс | `lsre_ghidra_open/_decompile/_strings/_xrefs` |
| Рантайм | `lsre_frida_status/_processes/_modules/_run` |

### Интерфейс
- **Чат** — обычный рабочий экран с карточками доказательств, планом шагов и счётчиком трат.
- **Код** — файлы проекта и просмотр содержимого (только чтение, до 6000 строк).
- **Архитектура** — карта узлов и связей сверху вниз: родители выше, дети ниже; перетаскивание,
  зум колесом, панорама, панель деталей, сохранение/загрузка карты в JSON.

### Память
- SQLite (WAL, FTS5) и гибридный поиск: BM25 + косинус эмбеддингов + свежесть (RRF), в ответе
  видно, **почему** факт всплыл.
- Эмбеддинги локальные: multilingual-e5-small int8, 384 измерения, 112,6 МБ, без сети.
- Банки памяти, наблюдения с числом подтверждений, страницы знаний, граф, якорь сессии.

## Что переработано нами (и что осталось от upstream)

### Взято из Craft Anything (MIT)
- оболочка на Rust/egui: экраны, карточки доказательств, проекты, настройки, CLI/MCP-паритет;
- механизм плагинов `[[plugins.mcp]]` — внешний MCP-сервер становится набором инструментов;
- структура проекта `.cany` (evidence, journal, annotations).

### Наше
- **движок** `engine/` — 28 инструментов, схема MCP **9,5 КБ**, память v2, гибридный поиск, эмбеддинги;
- **брендинг**: имя LSRE, векторная иконка-гарпия, каталог данных `lsre`, ресурсы exe;
- **разрешение в Clean room**: инструменты `lsre_*` не блокируются политикой;
- **вкладки «Чат / Код / Архитектура»** и вертикальная карта архитектуры (собственный экран);
- **пакетирование**: `start.cmd` + `start.cjs`, генерация конфига под папку, вложенный Node в full;
- **тесты**: 32 + 8 + 7 проверок, бенчмарк эмбеддингов (`bench`).

Подробный список — `docs/CHANGES.md`; архитектура — `docs/ARCHITECTURE.md`.

## Преимущества перед оригиналами

| | Craft Anything 0.5.0 | LSRE 2.1.0 (REA) | **LSRE 3.0.0** |
|---|---|---|---|
| Инструментов в MCP | 38 (всего 321) | 103 | **28** |
| Схема инструментов на запрос | 38,1 КБ | ~66–79 КБ | **9,5 КБ** |
| Локальные эмбеддинги | нет | rubert-tiny2 312d | **e5-small 384d** |
| Память между проектами | только папка проекта | банки SQLite | **банки + граф + страницы** |
| Kaitai / YAML / YARA | Kaitai и YARA частично | есть | **есть, одним пакетом** |
| Готовность «из коробки» | нужен агент/ключи | нужен REA-рантайм | **портативная папка** |
| Работа без сети | да | да | **да** |

Ключевое: **в 4 раза меньше схем на каждый запрос модели** при сопоставимом наборе локальных
инструментов — это прямая экономия токенов, а не «ещё одна обёртка». Сервер не зовёт LLM: все
ответы детерминированы и воспроизводимы.
